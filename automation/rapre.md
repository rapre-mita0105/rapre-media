# Rapre Instagram 自動投稿 手順書

この手順書は、無人の定期実行が毎回読み、次の投稿枠1回分を生成・予約するためのものです。

## 1. 投稿枠
- 毎週 月曜 08:00 と 木曜 21:00（Asia/Tokyo）。
- 1枠につき3件を同時刻に予約する: 通常投稿（カルーセル5枚）、リール、ストーリーズ。
- カテゴリーは次の順で1枠ごとに進める（6枠で1巡）:
  美肌 → 化粧品 → 姿勢 → 健康 → 食事 → カラダの不調
- 進行状況と過去テーマは automation/rapre-state.json に記録する。

## 2. アカウント情報
- サロン名: Rapre（Wellness & Beauty）／運営: 株式会社エレメンタルトリニティ／東京都港区
- 理念: 関わるすべての人に感動を与える
- コンセプト: エステを「特別なご褒美」から「健康習慣」へ
- 独自技術: ボディチューニング（骨盤矯正・筋膜リリース・ストレッチ）
- 対象: 美容・健康意識の高い40代女性
- 題材の参考: https://note.com/rapre_wellness と https://note.com/synca2025

## 3. テーマ選定
- 同じカテゴリーの過去テーマ（state の log）と科学的な切り口が重ならないこと。
- 候補を3つ以上出し、重複・根拠の弱さ・表現リスクの3観点で3回ふるいにかける。
- 根拠は皮膚生理学・筋肉生理学・栄養学の論文や公的機関の情報を、その回に実際に読んで確認できたものだけ使う。
  読めなかった資料、記憶だけの数値は使わない。確認できた根拠が無ければ、そのテーマは捨てる。
- 研究の限界（対象者、規模、関連か因果か）をスライド3枚目とキャプションに明記する。
- 毎回、Instagramの最新のアルゴリズム情報を検索して確認する。

## 4. 文章の規則
- 「肌」は「お肌」、「体」は「カラダ」と表記する（カテゴリー名の「美肌」は例外）。
- 敬語（です・ます調）。上品で静かな語り口。煽らない。
- 使ってはいけない表現: 治る、改善する、効果がある、解消、必ず、絶対、痩せる、若返る などの断定や効能の保証。
  医療行為と誤認される表現、他社の誹謗、ビフォーアフターの保証。
- キャプション本文は空白を除いて600字以上800字未満（ハッシュタグを除く）。
  構成: 共感の書き出し → 仕組み → 研究で報告されていること（限界つき）→ Rapreの取り組みと自宅でできること
  → 4択の質問と「番号でコメントをお寄せください。全て返信します。」→ 保存のすすめ → DMでのシェアのすすめ
  → 「Rapreは完全紹介制・完全予約制のプライベートサロンです。初回カウンセリングは無料です。ご予約・詳細はプロフィールのリンクよりお問い合わせください。」
- ハッシュタグは次の5個で固定:
  #美容サロン #ボディケア #介護脱毛 #白髪脱毛 #ボディチューニング
- 人物写真は使わない。

## 5. 生成
1. posts/rapre/<YYYY-MM-DD>_<英語の短い名前>/ を作り、post.json と caption.txt を書く。
   既存の posts/rapre/2026-10-12_skin/ を型として使う（5枚: hook, text, evidence, text, cta と story）。
2. `npm install` のあと `node tools/render.mjs posts/rapre/<フォルダ>` を実行する。
   「文字がはみ出しています」と出たら文章を短くして再実行する。
3. carousel の5枚と reel の数コマを実際に画像として見て、崩れや誤字が無いか確認する。

## 6. 検査（1つでも不合格なら予約しない）
- 文字数、ハッシュタグ5個、表記（体・肌）、禁止表現、予約動線の文、4択質問と「全て返信します」。
- スライドの記述が、その回に確認した根拠と一致していること。
- 不合格を直せない場合は予約せず、理由を最終報告に書いて終了する。

## 7. 保存と予約
1. main に commit して push する。
2. 画像と動画の公開URLは
   https://raw.githubusercontent.com/rapre-mita0105/rapre-media/main/posts/rapre/<フォルダ>/...
   取得できること（HTTP 200）を確認する。
3. Metricool（ブランドID 7099534、タイムゾーン Asia/Tokyo）に同時刻で3件予約する。
   - 通常投稿: instagramData.type=POST、media=carousel/slide_01〜05.jpg、text=caption.txt 全文
   - リール: type=REEL、media=reel/reel.mp4、videoThumbnailUrl=reel/cover.jpg、text=caption.txt 全文
   - ストーリーズ: type=STORY、media=story/story.jpg、text は送らない
   すべて autoPublish=true。同じ枠に既に予約がある場合は重複して作らない。
4. 予約を読み戻して3件あることを確認する。
5. automation/rapre-state.json の next_index を進め、log に日付・カテゴリー・テーマ・根拠を追記して push する。

## 8. 対象外
- コメントへの返信は代表本人が行う。自動では返信しない。
